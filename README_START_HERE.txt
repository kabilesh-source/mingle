VIBELY WINDOWS SETUP
1. Extract ZIP using Extract All.
2. Install Python 3 if needed (enable Add Python to PATH).
3. Double-click START_VIBELY.bat inside VIBELY_FullStack.
4. Browser should open. Otherwise go to http://localhost:8765
5. Keep black CMD window open.
If it fails, take a screenshot of the CMD error and send it.
Do not double-click public/index.html: the app needs server.py running.
