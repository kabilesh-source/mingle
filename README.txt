MINGLE - Windows + Phone Friendly Full Stack Starter
====================================================
1. Install Python 3 (if not already installed). No pip install or npm needed.
2. Extract this ZIP completely.
3. Double-click START_MINGLE.bat on Windows.
4. In your Windows browser, open http://localhost:8765
5. To open on your phone: connect phone and PC to the same Wi-Fi. Find the PC's local IPv4 address using ipconfig, then open http://PC_IP_ADDRESS:8765 on your phone. Allow Python through Windows Firewall on private networks if asked.
6. Leave the command window open while using the app. Close it to stop the server.

Included:
- Responsive mobile/desktop interface
- Register and log in with hashed passwords
- SQLite persistent database (mingle.db is created automatically)
- Discover real accounts created on this server
- Add friends and send/receive private messages (3.5 second refresh)
- Edit your profile
- Voice-room browsing UI (NO live voice calls)

Important:
- This is a local full-stack prototype, NOT a production-ready public social network.
- There is NO Android APK, push notifications, OTP, payments, gifts or real-time voice chat.
- Accounts are stored on your Windows computer, not on a cloud server.
- Do NOT port-forward this demo or expose it publicly. It lacks production security features such as HTTPS, persistent session storage, rate limiting, abuse moderation and account recovery.
- For internet-wide access, deploy to a secured server with HTTPS, authentication/session upgrades and appropriate moderation and privacy safeguards.
- Only use with adults 18+ until proper age assurance and safety controls are implemented.
